# Parallel Systems - Assignment 1: OpenMP Matrix Processing

Υλοποίηση παράλληλου προγράμματος σε **C** με τη χρήση της βιβλιοθήκης **OpenMP**, στο πλαίσιο του εργαστηρίου του μαθήματος **"Παράλληλα Συστήματα"**.

---

## 📋 Περιγραφή Εργασίας
Το πρόγραμμα εκτελεί επεξεργασία πινάκων σε παράλληλο περιβάλλον, υλοποιώντας τα παρακάτω επιμέρους ερωτήματα:

1. **Ερώτημα (a):** Παράλληλος έλεγχος αν ο πίνακας $A(N \times N)$ είναι «αυστηρά διαγώνια δεσπόζων» με χρήση προστασίας ατομικής εγγραφής (`#pragma omp atomic write`).
2. **Ερώτημα (b):** Παράλληλος υπολογισμός του μέγιστου κατ' απόλυτη τιμή διαγώνιου στοιχείου $m = \max(|A_{ii}|)$ με χρήση της ρήτρας `reduction(max)`.
3. **Ερώτημα (c):** Παράλληλη κατασκευή του νέου πίνακα $B(N \times N)$ αξιοποιώντας συγχώνευση βρόχων (`collapse(2)`).
4. **Ερώτημα (d):** Παράλληλη εύρεση του ελάχιστου στοιχείου του πίνακα $B$ με τρεις διαφορετικές μεθόδους:
   * **(d1)** Χρήση ρήτρας μείωσης (`reduction(min)`).
   * **(d2.1)** Χειροκίνητος υπολογισμός τοπικών ελαχίστων και προστασία με κρίσιμη περιοχή (`#pragma omp critical`).
   * **(d2.2)** Αλγόριθμος δυαδικού δέντρου (`Tree Reduction` με χρήση `single` και `barrier`).
